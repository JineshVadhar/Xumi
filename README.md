# Xumi – Interactive Desktop Companion Robot

Meet **Xumi**, a pocket-sized interactive desk companion robot designed to bring personality, emotion, and joy to your workspace.

Designed and crafted by **Yug Thakar**.

---

## ⚡ Key Features

- **Expressive Animated OLED Display**: Adorable, emotive pixel animations featuring sleep, happy, curious, focus, hungry, and playful moods.
- **Interactive Eye-Tracking**: Real-time cursor tracking on the OLED display test bench.
- **Capacitive Touch Sensing**: Tap to greet, stroke to soothe, double-tap to feed.
- **Dynamic Mood State Machine**: Evolves naturally through daily interactions without repetitive scripts.
- **100% Offline & Private**: Zero cloud telemetry, no smartphone app required, zero subscriptions.
- **Hardware Architecture**: 32-bit low-power SoC, rechargeable Li-Po cell via USB Type-C, and resonant acoustic micro-sound cavity.

---

## 🚀 Running Locally

No dependencies or build steps required. You can serve the static site using any local server:

```bash
# Python 3
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.
